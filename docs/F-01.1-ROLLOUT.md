# F-01.1 Pomodoro Focus Timer: rollout

What ships: the `focus` module (API `apps/api/modules/focus`, web `apps/web/src/modules/focus`), opt-in auto capture in the tracker, and the Slider, Tooltip and Kbd design-system components. Read this with `docs/F-01.2-ROLLOUT.md`; the timer depends on the tracker (`time_tracker` must work for the goal ring, history and reports).

## A. What you must configure

1. **PostHog flag `focus_timer`.** Create it. Without it the timer is on for everyone; set it to false to hide it. The API evaluates the same flag for the same user (needs `POSTHOG_API_KEY`, already used for `syllabus_coverage` and `time_tracker`), so a flag that is off also blocks the API (403 `feature_disabled`) and the web shows "not available yet". The mini timer only starts polling when its flag is on. `GET` and `DELETE /api/v1/focus/data/` are never gated.
2. **Migrations (once per environment, from your computer).** `cd apps/api`, export `DJANGO_SECRET_KEY` (any value locally) and `DIRECT_DATABASE_URL`, then `python manage.py migrate`. It applies `tracking.0002_auto_capture_setting` (one column on `tracking_trackersettings`), `focus.0001_initial` (`focus_focussettings` and `focus_activetimer`, with Row Level Security switched on after the migrate) and `focus.0002_overtime` (one column on each focus table). Nothing needs back-filling: a round that was already running keeps the classic behaviour.
3. **Throttle.** `focus_write` is 120 per minute per student (in `config/settings.py`). Override with the usual DRF settings if needed.
4. **Web.** No new variables. Redeploy after the API is live.

## B. Things to know

- Dependencies added: none (Slider and Tooltip come from the existing `radix-ui` package).
- The timer runs on the server clock. There is no worker or cron: phases settle when the timer is read or acted on, so nothing needs scheduling.
- Browser notifications need the student's permission and only fire while the tab is hidden. The chime needs one click on Start first, which is a browser rule.
- Auto capture is off for everyone until they switch it on in Tracker settings. It never runs while a timer runs or over recorded time, and is capped at 4 hours a day.
- `/features/pomodoro-focus-timer` and `/features/time-tracker` are in the provisional feature list with status `soon`. Change `status` to `live` in `modules/catalog/features.ts` when the flags are fully on.

- **Overtime (setting "Keep the timer running after the round ends", on by default).** A focus round that reaches its planned length does not stop: the clock turns into `+mm:ss` of extra focus, there is one chime and notification ("Round target reached") and no break starts. **Stop and save** (or `E`) counts the full time as a completed round and starts the break that is due (or waits when breaks are not automatic). It never runs unattended: if the tab has not been seen for two minutes the round closes at the last time it was seen, and the extra time is capped at two hours. Pausing freezes it; +5 minutes is unavailable once the round is running over. Turn the setting off for the old behaviour (the round closes itself at zero and the break starts).

## C. Check as a signed-in student

1. `/app/focus`: pick Deep, start, pause, resume, add 5 minutes, reload (the clock keeps its place), end early (save with a reason, then discard).
2. Let a short round run out with the tab open: the chime plays, the break starts, the tab title counts down. Leave the tab hidden through the end of a round for more than two minutes: the next visit asks "Did you study through that round?".
3. With auto-start of the next round off, let a break end: the page says "Start round 2 of 4".
4. Start the stopwatch at `/app/tracker`, then try to start a round: it is refused with a clear message. Do the reverse.
5. Open another `/app` page: the corner timer shows the round with a pause button. `/app/focus/history` lists the rounds (edit, delete, undo). `/app/settings/focus` changes presets, volume and notifications.
6. Offline: set the network to Offline, start and pause a round, go back online; the changes sync from the shared IndexedDB queue.
7. Auto capture: turn it on in Tracker settings, stay on a chapter page for six minutes, then look in the log for a `source=auto` row.
8. Switch all four themes and use only the keyboard (Space, S, E).

## D. Support and operations

- `ActiveTimer` and `FocusSettings` are read-only in the Django admin.
- Finished rounds are ordinary tracker sessions (`source = pomodoro`) and are repaired with `rebuild_tracking_rollups` like any other.
- A student can export and delete the timer and its settings in Focus settings, and their rounds in Tracker settings. There is no central account-deletion hook yet.

## E. Known limits

- Edits, deletes, merges and splits of a session append signed corrections to the coverage ledger, as in F-01.2.
- A round that would overlap another live session when the server settles it is dropped and logged rather than failing the request.
