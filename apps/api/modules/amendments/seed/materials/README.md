# Amendment PDF Materials & Ingestion Directory

Drop official authority notifications, Board of Studies (BOS) statutory updates, and Revision Test Papers (RTPs) here to be parsed and seeded into the Amendments Engine.

## Directory Structure

Organize files by course, level, and attempt:

```
materials/
├── ca/
│   ├── intermediate/
│   │   ├── 2025-05/
│   │   │   ├── paper-3-taxation-statutory-update.pdf
│   │   │   └── paper-2-corporate-law-amendments.pdf
│   │   └── 2025-11/
│   └── final/
│       ├── 2025-05/
│       │   ├── paper-3-advanced-auditing-standards.pdf
│       │   └── paper-4-direct-tax-amendments.pdf
│       └── 2025-11/
├── cma/
│   ├── intermediate/
│   └── final/
└── cs/
    ├── executive/
    └── professional/
```

## Supported Documents:
1. **Statutory Updates**: Periodic BOS booklets containing statutory amendments.
2. **Judicial Updates**: Case law summaries and court decisions.
3. **Academic Guidance**: Technical guides and study material errata/corrigenda.
4. **Clarification Circulars**: Institute notifications setting cut-off dates or applicability terms.
